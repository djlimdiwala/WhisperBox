# WhisperBox Roadmap

This roadmap outlines the planned evolution of WhisperBox from a learning project into a production-ready messaging platform.

---

# ✅ Completed

## Foundation

- Spring Boot project setup
- Maven configuration
- Java 17
- Git repository

---

## Database

- PostgreSQL
- Neon database
- Spring Data JDBC
- Flyway migrations

---

## Core Features

- Send message
- Receive messages
- Conversation history
- Read-once messages
- Automatic message expiration
- Scheduled cleanup

---

## Quality

- DTO architecture
- Validation
- Global exception handling
- Configuration properties
- User validation
